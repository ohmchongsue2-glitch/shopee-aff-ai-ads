การเชื่อมต่อ

กำลังตรวจ...

ค่าการเชื่อมต่อถูกบันทึกถาวรบนเซิร์ฟเวอร์ ช่อง Token และ API Key จะว่างหลังบันทึกเพื่อไม่แสดงค่าลับ เว้นว่างเพื่อใช้ค่าที่บันทึกไว้เดิม

System User ใช้สิทธิ์ที่มอบหมายใน Meta Business และช่วยลดการพึ่งพาการล็อกอินส่วนตัว ต้องสร้าง Token ใน Meta ก่อน เลือกอายุไม่หมดอายุเมื่อ Meta อนุญาต การยกเลิกสิทธิ์หรือข้อจำกัดของ Meta ยังทำให้เชื่อมต่อไม่ได้ ระบบตรวจ Token ใหม่ก่อนแทนค่าเดิม

แจ้งขั้นตอนและสถานะแอด • แจ้งทุกยอดสะสม 10, 20, 30… บาทต่อแอด • สรุปสถานะและการเชื่อมต่อทุก 1 ชั่วโมง • ตรวจทุก 1 นาทีตามข้อมูล Meta • แอดยังทำงานต่อ
